User feedback on chest pain page hero: "never forget to maintain proper spacing that how a generic and professional website is differentiated."

**Why:** When margins land at arbitrary values (20px, 24px, 30px) with no internal logic, the page reads as flat and unstructured. Premium sites use intentional rhythm — small gaps within a related group, larger gaps between groups — so the eye understands hierarchy without reading.

**How to apply** to every new section:

Use an 8-px scale: 8 / 16 / 24 / 32 / 40 / 48 / 56 / 64 / 80 / 96.

Group/intra-section rhythm:
- Eyebrow → H1: **16px** (tight — same idea)
- H1 → Sub-paragraph: **24px** (heading-to-body)
- Sub-paragraph → CTAs: **40px** (idea-to-action, bigger gap)
- CTAs → Trust strip: **56px** (primary-to-micro-trust, biggest gap)

Section-level padding:
- Root container top/bottom: **80px desktop**, 56px tablet, 48px mobile
- Heading-only sub-section: 48px top/bottom

Card / inner-container internal padding:
- icon-box card: 24-32px all sides
- Stat panel cell: 40px vertical, 32px horizontal

**The "professional" tell:**
- No three-line stack of 20/20/20 margins between unrelated elements.
- Always a hierarchy: tight (8-16) within a thought, breath (24-32) between thoughts, jump (40-56+) between sections of meaning.
- Generic sites use a flat 30px everywhere. Don't.
