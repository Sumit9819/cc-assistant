**HARD LESSON 2026-08-26 (verified by sweep + screenshots): never set kit `link_normal_color` or `link_normal_typography_text_decoration` site-wide.** `.elementor-kit-5 a {...}` outranks Elementor's button default (`.elementor-button { color:#fff }`) and hits menus: on Lufkin the kit link colour turned every button's text navy on red/black (90 new contrast failures), and the kit underline underlined every nav item and CTA on WR and Lufkin. Reverted (WR 1688; Lufkin 778/779) and replaced with kit `custom_css` rules scoped to text widgets: `.elementor-widget-text-editor a, .elementor-widget-theme-post-content a, .elementor-icon-box-description a, .page-content a, .entry-content a { color; text-decoration: underline }` (0,1,1 beats `.elementor a` by load order). Per-widget white overrides need (0,2,1): `.elementor-widget.elementor-element-<id> a`. IWC kept its kit link colour only because every IWC button carries explicit colours (sweep clean). Always screenshot nav + a button after any kit change (`scratchpad/shots.js`).
